# Repository Map

## Entry points

- `digital-protocell/Cargo.toml` — Rust workspace entry point.
- `digital-protocell/crates/experiment-runner/src/main.rs` — experiment and evidence pipeline CLI.
- `AGENTS.md` — Codex-first repository router.

- `digital-protocell/crates/chemistry-core/src/` — certified chemistry, mesh mechanics, transport, metabolism, growth, fission, and bounded post-Phase-1 extensions.
- `digital-protocell/crates/evolution-harness/src/` — protocol, event ledger, population, lineage, generation, adapter, qualification, and analysis contracts.
- `digital-protocell/crates/phase1-certifier/src/` — independent Phase 1 certification logic.
