# Repository Map

## Entry points

- `AGENTS.md` — canonical repository governance router.
- `.agent/` — adopted project goal, profile, current state, append-only ledgers, and historical handoffs.
- `digital-protocell/Cargo.toml` — Rust workspace entry point.

## Certified organism and mechanics

- `digital-protocell/crates/chemistry-core/` — certified material chemistry and mesh mechanics; frozen for DC-DEV-001A.
- `digital-protocell/crates/phase1-certifier/` — Phase 1 certification and regression checks.
- `digital-protocell/crates/experiment-runner/` — historical experiment orchestration; not changed by architecture selection.
- `digital-protocell/crates/evolution-harness/` — observer-only reusable evolution infrastructure; not extended by this directive.

## Strategy and evidence

- `digital-protocell/docs/strategy/` — historical strategy documents and the new developmental/sensorimotor documentation.
- `digital-protocell/experiments/generated/` — generated evidence and provenance; historical evidence is preserved and not rewritten.
- `digital-protocell/experiments/generated/dcdev001/` — machine-readable DC-DEV-001A decision artifacts.

## Governance and storage

- `.agents/skills/authority-governance/SKILL.md` — adopted governance workflow.
- `.agents/skills/external-discovery/SKILL.md` — required source-level prior-art workflow.
- `.cursor/` — compatibility adapters and verified repository-owned configuration.
- `scripts/validate_governance.py` and `scripts/test_validate_governance.py` — governance validation.
- `STORAGE_MAP.md` — canonical external storage locator.
- `docs/storage_archive_policy.md` — storage handling policy.

## Developmental/sensorimotor deliverables

- `digital-protocell/docs/strategy/developmental_sensorimotor/` — human-readable DC-DEV-001A analysis and decision.
- `digital-protocell/experiments/generated/dcdev001/` — deterministic machine-readable manifests and matrices.

## Areas not authorized for this directive

- Certified organism source and equations.
- D-096/D-098/R1/R2/R3/R4 scientific implementation and generated evidence.
- Production learning, memory, motor behavior, webcam/microphone processing, and evolutionary selection.
