## Architecture comparison

### A — qualified whole-membrane reproductive reference

Useful as a throughput and fission calibration. It is not a finite spatial
ecology: it does not establish separated local encounter, shared environmental
ownership, or resource-causal reproduction in the target setting.

### B — hard-contact finite spatial field / shared medium

Already tested with finite world ownership, local exposure, conservation, and
transfer-disabled controls. The two implementations differ in allocation and
ownership semantics, but both leave the current path below resource-causal
reproduction. Treating a third discretization as a new hypothesis would be
representation search, not architecture progress.

### C — persistent organism assimilation state

Scientifically coherent as a possible uptake-to-processing compartment and
focused preservation evidence exists. It changes core chemistry state,
validity, observer death semantics, serialization, remesh, and fission
partitioning. It is therefore `INVESTIGATE_NOT_ACCEPTED`, not a harmless assay
wrapper and not a license to add another downstream pool.

### D — materially different environmental transport boundary

This is the only remaining architecture category that could address the R10
first divergence without changing the frozen growth/fission laws. It must be
different in physical ownership or transport semantics, not merely a finer
grid, a new exposure expression, another intracellular buffer, or a changed
resource amount. Existing spatial nutrient models support the general category
of finite extracellular transport with local cell sinks, but they do not supply
Digital Cell parameters or authorize implementation.

At present no objective source-level contract for D has been selected. The
existing `SpatialMaterialFieldV1` already covers the obvious finite continuum
discretization category. A future proposal must therefore identify a genuinely
different invariant-preserving boundary before runtime work resumes.

## Required contract before any successor runtime

A proposed successor must state, before implementation:

1. the finite owner of every environmental N/F unit;
2. the exact local transport boundary and control-volume semantics;
3. why it is materially different from both Route-B and the R11/R12 shared
   medium;
4. the first causal checkpoint at which transfer precedes growth/fission;
5. the same common flux ledger through transfer, processing, A/W, maintenance,
   active work, growth, structural mass, and fission;
6. transfer-disabled, multi-organism, restart, remesh, and fission controls;
7. preservation evidence for every changed core state if assimilation remains;
8. a fixed stop condition preventing another representation or throughput
   search if the first transfer divergence remains.

No new gain, threshold, timer, fission-gate change, resource increase,
resource repositioning, horizon extension, controller signal, or observer
allocation is permitted.
