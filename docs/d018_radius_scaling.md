# D-018 Radius Scaling

| Quantity | Exponent | Class |
| --- | --- | --- |
| B_structure (production basis) | p ≈ 1.0621258840309338 | interface_scaled |
| L_structure (decay) | q ≈ 1.9847973829339534 | bulk_scaled |
| k_required | q−p ≈ 0.9226714989030196 | — |

Production is primarily **interface-scaled**; decay is primarily **bulk-scaled**.
Required rate therefore rises with radius (~R^0.9), so a single constant `k_structure` cannot restore a structural nullcline across R=14–34 once the live A field is established.
