# Quarantined independent source evidence

Source: Alex Albaugh and Todd R. Gingrich, *Simulating a Chemically-Fueled
Molecular Motor with Nonequilibrium Molecular Dynamics*, Zenodo record 4481182,
version v1, published 2022-02-02, DOI https://doi.org/10.5281/zenodo.4481182.
Related journal article: https://doi.org/10.1038/s41467-022-29393-3.
The source repository metadata declares Creative Commons Attribution 4.0:
https://creativecommons.org/licenses/by/4.0/ . Attribution and original member
names are retained. No source/member contents were modified or executed.

The binary payload is a **sparse HTTP range**, not the complete ZIP. It contains
original archive bytes 0–199999. The central directory and tail are separately
preserved. The original source archive has 551,498,479 bytes and advertises MD5
75c151155bd3187cb1e56e07539887f4. That whole-archive checksum is NOT VERIFIED here.
HTTPS acquisition, exact Content-Range checks, original member CRC and local
SHA-256 bind the selected material; CRC is not publisher cryptographic attestation.

The initial selection was sealed before inspecting its member contents: all 18
source-code files, root/data readmes and all four processed figure-3/4 tables.
Two complete plot scripts were subsequently selected as column-context evidence,
following the acquired data README, with a separate preregistration before their
inspection. They were not executed. The receipts bind 26 original members.

Original C++/Python source is present only as nonexecuted archive bytes in this
package; it is not incorporated into Digital Cell runtime or verification imports.
The four tables contain 44 headerless rows, each with 23 finite numeric values.
These are published processed computational summaries, not acquired raw replicate
trajectories or Digital Cell calibration observations. No row is dropped or fitted.
All Digital Cell source/variable/unit/uncertainty/seal gates remain separate.

Primary article HTML documents were acquired into the external local/archive
evidence root, not redistributed in this Git package. Their IDs, URLs and hashes
are recorded in primary-document-receipts.json. Their existence is documentary
evidence, not a raw experimental-data registry.
