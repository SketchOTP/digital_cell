# Failure taxonomy

The versioned `FailureClass` distinguishes harness-invalid, founder-invalid, population collapse, zero/insufficient generation, ecology pressure not reached or post-reproduction, no reproduction, heredity/phenotype failure, numerical/resource failure, incomplete lineage, valid no-effect, valid effect, and interpretable timing.

`SELECTION_UNTESTABLE_ZERO_GENERATION` is intentionally separate from `VALID_NO_SELECTION_EFFECT`. The former means the experiment never reached a causal reproduction window; the latter is reserved for a viable experiment that reached its declared generation requirement and observed no differential effect.
