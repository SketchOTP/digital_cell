# Failure taxonomy

The versioned `FailureClass` distinguishes harness-invalid, founder-invalid, population collapse, zero/insufficient generation, ecology pressure not reached or post-reproduction, no reproduction, heredity/phenotype failure, numerical/resource failure, incomplete lineage, valid no-effect, valid effect, and interpretable timing.

`SELECTION_UNTESTABLE_ZERO_GENERATION` is intentionally separate from `VALID_NO_SELECTION_EFFECT`. Replicates first receive `REPLICATE_QUALIFIED`; only a treatment/neutral campaign comparison can produce a valid selection verdict. A valid-no-effect result therefore requires actual reproduction, reached pressure, correct pressure timing, viability, heredity, measurable phenotype, a valid neutral comparator, and a valid event ledger.
