# Tier 2 world/GPU synthesis

`TIER2_WORLD_GPU_AUDIT_COMPLETE`

Ribossome is a useful modern wgpu pattern source; ALIEN is a useful data-oriented CUDA/HIP architecture reference. Neither is a compatible Digital Cell world: both grant runtime organisms and derive bodies/behaviour from genome or neural structures rather than conserved material mesh state. Their rendering/UI and organism cores are too coupled for safe extraction.

Keep the current CPU/Godot path. GPU/world work is not authorized by this directive and there is no measured scaling requirement. If a future need is demonstrated, choose `ADOPT_WGPU_ARCHITECTURE_LATER`: build a thin Digital Cell-owned backend from isolated buffer/pipeline/profiling patterns, with CPU parity and certifier comparison. Do not migrate to CUDA/ALIEN and do not port organism shaders. No GPU or world source was integrated.
