# CAX, Lenia and Flow Lenia

Lenia (`Chakazul/Lenia`, commit `adfc542939266de7f4bb7ebb552e8499701ee107`, MIT in `LICENSE.md`) and Flow Lenia (`erwanplantec/FlowLenia`, commit `dce428c6b0c5079a06e5606fb7b5ac1fe1323bc5`, no license file found) implement grid-based continuous cellular-automaton surrogates with FFT kernels, rollout scans, mass/statistics and rendering. Flow Lenia uses Python/JAX and `lax.scan`; Lenia also has Python, JavaScript and Matlab paths.

These are useful `BENCHMARK`/`DEFER` references for local rules, mass transport, morphology and fast surrogate experimentation. They do not model Digital Cell material conservation, membrane boundary, chemistry, or fission. Flow Lenia is `NO_CODE_REUSE_UNTIL_RESOLVED`; CAX source identity was not resolved in the audit and remains `SOURCE_IDENTITY_UNRESOLVED`. No source was copied.
