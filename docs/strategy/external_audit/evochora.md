# Evochora

Source: `evochora/evochora`, commit `7b45ae32d83f1cec7bce3bcd011ea29a375cf92b`, tree `efa76c06a0e7abb058d516d4234fc283223e8265`; MIT in `LICENSE`; Gradle/Kotlin/Java.

Evochora combines compiler/assembly/runtime VM layers with environment, molecule and organism models, mutation plugins, SPI extension points, birth/death, serialization, H2-backed persistence, queues, analytics, HTTP controllers and visualization/video services. Its distinct value is the separation of runtime, plugin, persistence and analysis concerns rather than a compatible organism substrate.

Disposition: `BENCHMARK`/`DEFER`; use it to compare runtime/data/analytics boundaries and do not introduce a second framework into Digital Cell. No code or dependency was integrated.
