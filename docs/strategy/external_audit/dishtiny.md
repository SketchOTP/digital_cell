# DISHTINY

Source: `mmore500/dishtiny`, commit `9a23e2fa9476bdb04e69e9f9f675b3650b9a334b`, tree `eb0b605ea521829a2c01d42438183d3f1a52cd6c`; MIT in `LICENSE`; C++/Makefile with extensive Python analysis.

The dish2 library includes genomes, generation/mutation counters, parent/child events, resource stockpiles and transfer, resistance/reserve, kin groups, apoptosis, fragmentation and group-level analysis. It is a valuable future baseline for multicellular individuality, cooperation, communication, division of labour and group reproduction.
