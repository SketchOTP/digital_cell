# Aevol

Audited mirror: `tgrohens/aevol`, branch `aevol-9`, commit `2ebc0dfe26f8d7aed6baf1e4d31e0c9b0fcac2d9`, tree `6bb330ab4cd58e5c15eba8fb31c16a84f4c4fd4a`; GPL-3.0 in `COPYING`; CMake/C++. The mirror describes itself as a local copy of the INRIA source; canonical-host provenance remains separately noted in the manifest.

`Dna` implements point, insertion/deletion, duplication, deletion, translocation and inversion mutations with reports/metrics. `Individual` derives a fuzzy phenotype from a circular binary genome and computes fitness from metabolic error. `Selection` supports global/local and rank/exponential selection; population and phylogeny handlers support long-term analysis, robustness, evolvability and complexity studies.

Use as a benchmark for mutation reporting, phylogeny, robustness/evolvability and environment-target analysis. The genotype-to-phenotype and fitness model is not a material mesh. Classification: `BENCHMARK` / `ADAPT` data methodology, `REJECT_INTEGRATION` source because GPL-3.0 and incompatible organism semantics. It does not replace Digital Cell template heredity or fission.
