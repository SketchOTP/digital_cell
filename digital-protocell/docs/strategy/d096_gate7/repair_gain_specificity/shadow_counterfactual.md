# Fixed shadow counterfactual

The sole diagnostic counterfactual is fixed before interpretation:

`J_shadow = J_base + J_strain * g_repair`

Baseline/homeostatic build receives no repair gain; only the strain-responsive component receives it. Processing, activation, reserve, growth gain, mechanics, topology, environment, genotype, and numerical parameters remain unchanged.

The shadow is explicitly non-authoritative and cannot qualify a repaired organism. Protocol, rows, and summary are in `experiments/generated/sr004cr3/`.
