# Physical-substrate compatibility

The same shared Gate 5 founder and chemistry were run with mechanics and the
existing remesh/topology path enabled, while fission remained disabled.

The B reciprocal effect remained positive for every paired seed, with mean
effect `13.485368698695993` versus neutral `13.454270301885149`.

The H reciprocal effect failed: processing-heavy minus repair-heavy reserve
effect was `-10.420576576644205`, with per-seed positivity false. The neutral H
effect was `-18.680501643321076`. Because the required H criterion is
per-seed positivity, R2 stops here and does not repair mechanics or physiology.
