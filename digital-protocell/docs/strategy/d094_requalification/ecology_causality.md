# Ecology causality

## Gate 6 classification

`D094R2` is `COMMON_ENVIRONMENT_INDEPENDENT_RESOURCES`.

The source comment and implementation create parallel single-founder
`MeshPopulation` lineages under one ecology clock. Each lineage receives the
same exterior field schedule, but an organism's uptake does not reduce a
finite pool available to another lineage. Therefore this is not
`TRUE_SHARED_FINITE_RESOURCE_COMPETITION`.

- finite resource: no;
- organisms causally compete for resource: no;
- pressure before reproduction: the source schedules H/B interventions, but
  the historical analysis did not emit a causal phenotype-specific
  pressure-to-reproduction measure;
- identity-blind damage: yes for the B abrasion operation;
- clade feedback: none; clade is observer metadata only.

## Adapter decision

No new population/ecology adapter was added. The accepted harness can fail
closed for shared/spatial resources, and the Gate 8 decision does not justify a
new selection campaign. A future ecology adapter, if separately authorized,
would need a finite resource ledger and conservation checks before calling the
experiment competition.
