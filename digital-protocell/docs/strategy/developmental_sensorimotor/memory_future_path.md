# Memory and identity future path

Memory is deferred, but the architecture must leave a lawful path for it. The first future memory layer is local persistent regulatory state with explicit initialization, update, decay, and fission provenance. A later identity layer may derive continuity from conserved material lineage, persistent local state, and event history; it may not be a globally assigned identifier that creates individuality by fiat.

No current result claims memory, learning, self-model, or identity. A future memory directive must define whether state is copied, partitioned, or regenerated at fission, how mutation is separated from physical material, and how replay proves continuity. Any learned parameter must remain local, bounded, versioned, and causally connected to sensorimotor outcomes without becoming a fitness function.
