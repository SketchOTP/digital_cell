# DC-DEV-002 — Minimal Distributed Regulatory Substrate

DC-DEV-002 adds one bounded observer-only regulatory state per current
material-mesh vertex.  It reads a narrow immutable local frame, couples only
to the two immediate closed-ring neighbors, and exposes no organism command.

The material mesh remains the organism.  This package does not implement
development, sensing in general, memory, learning, behavior, effectors, motor
control, evolution, or topology-state transfer.

The frozen gate package is generated under
`digital-protocell/experiments/generated/dcdev002/` by the
`dcdev002_gate_assay` example.
