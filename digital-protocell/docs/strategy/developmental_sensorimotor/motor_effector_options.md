# Motor effector options

Effectors are bounded requests to existing material mechanisms. Candidate effectors are local transport modulation, catalyst-expression modulation through existing chemistry, local growth tendency, and approved membrane/topology adjustments if an existing API exposes them.

An effector may be rejected when the mesh cannot represent it without new biology. The contract forbids direct coordinate teleportation, arbitrary material creation, direct fission authorization, and population culling. Every accepted intent must produce an event/provenance record and remain replayable from local state plus the accepted simulation-time increment.
