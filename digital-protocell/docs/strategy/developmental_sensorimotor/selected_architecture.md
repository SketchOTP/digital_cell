# Selected architecture

## Conclusion

`DCDEV001_HYBRID_COMPOSITION_SELECTED`

The selected architecture is a Digital-Cell-native distributed regulatory patch system informed by external patterns. It combines the locality and sensor/effector separation visible in ALIEN, the development/regeneration intuition of NCA, and the local signaling vocabulary of DISHTINY, while preserving the Digital Cell material mesh, chemistry, transport, growth, and fission as the only causal organism authority.

## What is selected

* persistent local regulatory state coupled to bounded material patches;
* local sensor transducers for already-authoritative physical quantities;
* local effector intents routed through existing bounded mechanisms;
* deterministic accepted-time updates and append-only provenance;
* future extensibility to a local graph/spiking implementation behind the same interface.

## What is not selected

No external source code or runtime; no genome-built body; no CA replacement mesh; no central controller; no target shape; no fitness scalar; no selection campaign; no learning or memory claim; no D-096 re-entry.
