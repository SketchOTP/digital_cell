# DC-DEV-003 — Regulatory continuity through body growth/remeshing

This package implements only continuity of the accepted DC-DEV-002 local activity field while one existing material organism undergoes ordinary mesh remeshing.

The regulator observes immutable before/after local material frames. It does not decide growth, mechanics, remeshing, death, or fission. Supported transitions are stable topology, local split, and local merge. Fission and unknown topology events fail closed.
