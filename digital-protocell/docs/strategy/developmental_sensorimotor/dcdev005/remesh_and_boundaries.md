# Continuity and Unsupported Boundaries

During the 1000-step body-continuity assay, ordinary split/merge mappings from
DC-DEV-003 transfer both regulatory activity and the one local adaptation
trace. The trace remains a per-patch vector; no global redistribution occurs.

Fission is disabled in the growth/remesh assay. Both the continuity network
and `PlasticityStateV1::remap` reject a fission topology event. No fission-state
inheritance is claimed.

The package does not add sensors, actuators, semantic commands, reward,
fitness, target behavior, learning optimizers, neural-network machinery, or
evolution.
