# Habituation and Recovery Assay

The assay constructs one standardized tensile perturbation and derives one
deterministic current regulatory activity vector from that same material
frame. The experienced state receives 40 identical exposure steps, each on a
fresh copy of the same perturbed mesh, so physical present state and current
activity do not accumulate as confounders.

The final experienced response is compared with a time-matched naive state
that receives the same perturbation and activity once. Contractile response is
the existing DC-DEV-004 maximum edge tension. The required result is a lower
experienced response with identical present input.

Recovery applies 200 accepted zero-activity steps, then repeats the same test.
The trace must decrease and the response must move back toward, without
requiring perfect equality with, the naive response.
