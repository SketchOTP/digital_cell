# External landscape

The audit is source-level and pattern-oriented. It does not authorize code reuse.

* **ALIEN**, live HEAD `10fea73fe9a2f7a587c57d833f252425a0106b72`, BSD-3-Clause: the audited engine/entity and neural/sensor/muscle data structures, processor/kernel split, spatial maps, and persistence layers show particle organisms, genome-built neural networks, sensors, and muscles. Useful as a distributed sensor/effector and data-oriented systems reference; CUDA and genome-built body assumptions are incompatible with the material mesh.
* **Ribossome**, live HEAD `cb3bb85f12b8aad44969437de56696583f8847b8`, MIT: audited `src/main.rs` and WGSL compute paths show wgpu device/pipeline/buffer setup, packed genomes, chemical/fluid grids, spawn requests, readback, and profiling. Useful for future infrastructure only; its genome directly constructs the body and its reproduction grants runtime agents.
* **DISHTINY**, live HEAD `9a23e2fa9476bdb04e69e9f9f675b3650b9a334b`, MIT: audited `dish2` sources show local stockpiles, resource transfer, channels, adjacent reproduction, kin, apoptosis, fragmentation, and group events. Useful for local signaling and life-history vocabulary; it is a multicellular/ecological model, not a replacement for conserved fission.
* **Growing Neural Cellular Automata**, Distill 2020 and the Google self-organising-systems repository at live HEAD `3d5547ca48b60ecac459834e2c05c9ff5df87991`: local update rules, developmental growth, regeneration and damage recovery. Useful as a conceptual development/regeneration pattern; a CA grid is not a material mesh and must not become the causal substrate.
* **Polyworld**, live HEAD `99debe8c40fd9f8e58eaae49bb86a68fd1af3703`, APSL-2.0: neural/behavioral agent and sensory baselines. It is a historical benchmark only, with legacy assumptions and no safe direct integration.

The binding result is that no external project supplies a safe drop-in developmental sensorimotor architecture. The correct transfer is a small set of concepts into a Digital-Cell-owned local regulator.
