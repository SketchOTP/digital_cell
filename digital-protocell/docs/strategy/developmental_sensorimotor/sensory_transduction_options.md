# Sensory transduction options

Sensors must be transducers from existing physical quantities into local bounded signals. Initial candidates are:

* local substrate/resource and catalyst quantities;
* membrane area, perimeter, curvature proxy, and reserve where already exposed;
* local transport flux and neighbor contact/topology;
* damage or perturbation events already represented by the authoritative mesh/evidence interfaces.

Each sensor returns a versioned, dimensioned value with provenance and saturation behavior. It does not inspect a global population, future state, fitness, or hidden target. Sensor noise, if introduced later, must be explicit and seeded; it must not be used to manufacture selection evidence.
