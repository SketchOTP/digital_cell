# Evolution re-entry path

Evolution is deliberately deferred. Re-entry requires a separate directive after the developmental/sensorimotor architecture has a causal implementation and independent evidence.

The minimum future gates are: local regulator expression; real sensor-to-effector causality; persistent state across accepted steps; physical fission continuity; lawful state inheritance or regeneration; neutral controls; independent replicates; no central controller; no assigned fitness birth rule; and an append-only evidence ledger. Only then may a future campaign ask whether variation and differential persistence arise naturally. D-096 is not revived by this document.
